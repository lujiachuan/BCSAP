# UI M2–M4 改造与验收报告

> 范围：在已有 M0/M1 基础上完成专业图表、交互动效、响应式设置页、图标比例修复与自动化验收。

## 1. 已完成内容

### M2 核心业务页

- 新增 `apps/desktop_client/spectrum_plot.py`，扫谱与自动调束已从手绘 `LinePlot` 切换到 pyqtgraph；
- 支持缩放、平移、视图复位、约 30Hz 十字光标读数和受限峰值标注；
- 显示层启用可视区裁剪与峰值保持型自动降采样；原始数据单独保留，避免导出降采样数据；
- 扫描期间固定目标范围，结束后标注主要峰值，避免自动范围持续跳动；
- 自动调束保留三阶段结构，实时指标增加宽度预留，降低数字更新抖动；
- 设置页改为“左侧分组＋右侧详情”，宽度不足 900px 时自动切换为顶部选择器；
- 占位页补充模块范围与计划能力，不再显示空白面板。

### M3 交互与动态效果

- 新增 `apps/desktop_client/motion.py`，页面切换使用可取消、单实例淡入；
- 系统设置增加“减少动态效果”，启用后关闭页面淡入、侧栏宽度动画和运行态脉冲；
- 服务状态点仅在 `running` 状态脉冲，正常/警告/错误状态保持静态；
- 主题切换会刷新 pyqtgraph 图表、状态组件、导航图标与原生标题栏。

### M4 稳定性与视觉收尾

- 修复导航图标 DPR 二次缩放：设置 DPR 后不再对 Painter 重复缩放；
- 导航、菜单、太阳和月亮图标分别校准视觉占比，并通过透明边距测试防止裁切；
- 数据服务与仪器服务地址改为并行探测；仪器可达后继续检查全部 PV；
- 初始化必要检查完成后允许进入，数据同步继续执行，保留离线/降级进入和单项重试；
- 滚动区背景改为显式 viewport 样式，移除依赖内部层级的脆弱选择器；
- 截图工具适配新的响应式设置页。

## 3. 仍需真机完成的验收

以下项目依赖真实显示设备或外部服务，离屏自动化不能替代：

1. Windows 10/11、100%/125%/150%/200% DPI 肉眼走查；
2. 1366×768 实机上表格、设置页与图表操作密度确认；
3. 真实数据服务的全量/增量下载、断网恢复和磁盘容量边界；
4. 真实仪器执行服务与全部 PV 的连接压力、超时和失败原因映射；
5. 50,000 点约 14Hz 连续 10 分钟，以及整机 30 分钟内存稳定性记录。

上述内容属于部署环境验收，不影响当前软件实现和自动化回归结论。Windows Acrylic/Mica 和自绘无边框标题栏仍按方案作为可选增强，不属于主线完成条件。
